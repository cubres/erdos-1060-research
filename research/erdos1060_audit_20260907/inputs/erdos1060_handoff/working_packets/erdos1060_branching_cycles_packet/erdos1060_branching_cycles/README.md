# Erdős 1060: branching certificates and quadratic feedback

## Status

This packet contains proved partial results and exact experiments. It does not contain a proof of the unrestricted Erdős conjecture. No originality claim, independent human-referee approval, or proof-assistant certification is asserted.

The central proved bound is

    f_2(N) <= 9 * 3^b(N) * 2^r(N),
    log max(1,f_2(N)) <= (b(N)+2) log 3 + sqrt(log 2 * log N).

Here f_2 restricts inputs to cubefree integers, b(N) counts vertices in strongly connected components of size at least three in the specified admissible divisor-sum graph, and r(N) counts size-two components. The graph is target-specific and includes every admissible local exponent, not just exponents used in an already known solution. A uniform little-o estimate for b(N), or for the adaptive reconstruction cost, is not proved.

The proof also gives a large-prime forcing/lifting theorem for exponent caps 1, 2, and 3, and a general branching-certificate counting lemma. The classical quadratic-pair classification is explicitly credited to Bibby, Vyncke, and Zelinsky. See the PDF for complete definitions, hypotheses, proofs, and source references.

The verifier independently enumerates every cap-two divisor of each target generated by a cubefree seed input at most 1500, then tests the divisor sum by direct summation. It verifies 1248 seed-target cases, not 1248 distinct targets. Its large-target checks rerun the same inverse-search algorithm; they are not an independently implemented second large-target enumeration.

## Use the solver

```python
from branch_solver import ExactSolver, BudgetExceeded

# 336 = 2^4 * 3 * 7. E=2 means cubefree inputs.
solver = ExactSolver({2: 4, 3: 1, 7: 1}, E=2, seconds=30)
try:
    result = solver.solve()
except BudgetExceeded:
    result = solver.result(False)

print(result["complete"])
print(result["solutions"])  # ['12', '14'] when complete
```

Use `E=None` for all possible input exponents. A `complete: false` record is explicitly incomplete and must never be used to claim nonexistence or exact multiplicity. Timing values are hardware-dependent. The supplied runs all completed.

## What the branching counts mean

The program repeatedly applies exact single-row support tests, then one-step lookahead with the same propagation. When alternatives remain, it selects the next variable by a deterministic score involving the propagated child domains; it does not use the known completed fiber.

`max_success_depth` counts actual branch nodes on a successful path. It is not the number of arithmetic operations, candidate tests, or propagation calls. Not every branch is binary.

`max_success_cost_product` is the maximum product of branch arities along a successful path. The successful leaves are bounded by that product by the proved random-branch argument. A node that is forced after lookahead costs no decision bit, but its lookahead computation may be expensive. No polynomial-time complexity result is claimed.

## Scope of the experiments

The previously supplied 58-digit target M has exactly two preimages, and this rule determines each after one binary choice at prime 11. The 61-digit target 336M has four cubefree preimages and six unrestricted preimages. One test target has seven unrestricted preimages. No minimality or record claim is made.

Five selected scaled cap-two targets have 58, 98, 138, 218, and 379 digits, each with two preimages and one charged binary decision. Twelve selected represented targets have unique preimages at their requested caps. These observations do not establish any unbounded-target asymptotic theorem.
